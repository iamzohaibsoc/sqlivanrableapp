' UNION SELECT sql,NULL,NULL FROM sqlite_master WHERE name='secret_users'--
Concept: SQLite has sqlite_master (instead of MySQL's information_schema) which stores all table definitions. By querying this system table, an attacker can fully map the database structure — discovering hidden tables, columns, and even the complete CREATE TABLE statements.
