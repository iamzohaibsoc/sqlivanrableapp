Concept: Every database engine has a built-in function that reveals its version. Knowing the DB type helps tailor further attacks. In SQLite, use sqlite_version(). In MySQL/MSSQL, you would use @@version. This lab simulates the concept using SQLite's function.

📖 Vulnerability Explanation

Vulnerable Code:

query = f"SELECT id, name, description FROM products WHERE name LIKE '%{search}%'"
cursor.execute(query)

Safe Code:

query = "SELECT id, name, description FROM products WHERE name LIKE ?"
cursor.execute(query, (f"%{search}%",))

Attack: Inject ' UNION SELECT sqlite_version(),NULL,NULL--.
The version string (e.g., 3.45.1) appears in the first column!

Note: In real MySQL, use @@version or version().
