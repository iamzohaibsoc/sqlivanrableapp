Welcome to the SQL Injection Laboratory

This application is vulnerable to SQL Injection attacks. It is designed for educational purposes to help US understand how SQLi vulnerabilities work and how to defend against them.

📋 Assignment Overview

This lab covers all 8 SQL Injection vulnerability types from the PortSwigger Web Academy.
