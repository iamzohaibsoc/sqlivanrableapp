📖 Vulnerability Explanation

Vulnerable Code:

query = f"SELECT id, name, price FROM products WHERE name LIKE '%{search}%'"
cursor.execute(query)

Safe Code:

query = "SELECT id, name, price FROM products WHERE name LIKE ?"
cursor.execute(query, (f"%{search}%",))

Attack: The query returns id (int), name (text), price (int).
Try ' UNION SELECT 'a',NULL,NULL-- → type mismatch error (id is int).
Try ' UNION SELECT NULL,'a',NULL-- → success! Column 2 is text.
