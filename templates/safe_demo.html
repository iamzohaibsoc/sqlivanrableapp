📖 Secure Implementation

Secure Code:

query = "SELECT * FROM products WHERE category=? AND released=1"
cursor.execute(query, (category,))

Why it's safe: The ? placeholder ensures user input is treated as data only, never as executable SQL. Even if you input ' OR 1=1--, SQLite treats it as a literal string value for the category column.

Try it: Enter ' OR 1=1-- — it will search for a category literally named ' OR 1=1-- and return nothing (unless such a category exists).
